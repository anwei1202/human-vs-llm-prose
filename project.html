Distinguishing Human and LLM-Generated Text Using Linguistic Features

Author

Anwei Yan, Ting Chen, Kevin Bao

Summary

As AI-generated content becomes increasingly prevalent, understanding how machine-generated language differs from human writing is important for detection, evaluation, and broader applications in natural language processing. This project investigates whether linguistic features can distinguish between human-written text and text generated by large language models (LLMs). Using the dataset Human-AI Parallel English Corpus (HAP-E), we analyze the quantitative linguistic features capturing multiple aspects of text. Our goal is to examine how the source of a piece of text associates with its linguistic features, and whether these features can be used to reliably predict its source.

Our analysis shows that human- and LLM-generated texts differ systematically across multiple linguistic dimensions. Exploratory analysis, logistic regression, and supervised modeling indicate that linguistic features can meaningfully predict whether a text was written by a human or generated by a language model. In particular, features related to pronoun usage, tense, sentence structure, and subordination were among the most informative signals. Broadly, LLM-generated text tends to rely more on generalized and structurally complex language, while human writing appears more context-dependent and referentially grounded. At the same time, these differences are highly feature-specific, meaning variables within the same linguistic category may show contrasting effects.

However, unsupervised analyses produced a different conclusion. Principal Component Analysis and hierarchical clustering did not reveal strong natural separation between human and LLM-generated texts. Instead, observations from different sources substantially overlapped in reduced feature space, suggesting that many broad stylistic patterns are shared across human and machine writing. This indicates that the selected linguistic features are more effective for supervised classification and interpretation than for clear unsupervised clustering.

We also found measurable differences among model types. Instruction-tuned and non-instruction-tuned LLMs displayed distinct linguistic tendencies, indicating that training objectives influence writing style. Overall, these results suggest that linguistic features capture subtle but meaningful signatures of both authorship source and model tuning, even when those differences are not strong enough to form clear natural clusters.

Overall, this project explores how linguistic features provide an interpretable but limited framework for understanding and distinguishing between human and machine-generated text.

Data Overview

We use the Human-AI Parallel English Corpus (HAP-E), Biber dataset, available from CMU S&DS Data Repository. This dataset is built from 12,000 original texts collected from a variety of real-world. For each original text, two chunks of about 500 words were extracted. The first chunk was used as a prompt for large language models, asking them to continue the text in the same style. The second chunk, written by the original human author, was then compared to the version generated by the LLMs. This creates a parallel structure where human and AI-generated text can be directly compared. Each row in the dataset represents one 500-word text chunk. The dataset includes both human-written text and text generated by several LLMs, including models such as GPT-4o and Llama.

For our analysis, we define the independent variable to be source_type:

  • Human: the original chunk written by humans
  • LLM: the generated continuation produced by different LLM models, including both pretrained and instruction-tuned versions.

As response variables, the corpus presents 66 linguistic features derived from multidimensional register analysis (Biber 1988). These features capture a comprehensive quantitative summary of the text (rate as per 1000 words) of dimensions, including tense and aspect, pronouns and reference, syntactic structure, lexical complexity and discourse markers. The numerical features allow us to analyze writing style in a structured way and compare how human and LLM-generated texts differ.

Research Questions

In this research, we aim to answer how linguistics features associate with source in different ways. We will focus on the following three aspects.

  • Can linguistic features distinguish between human- and LLM-generated texts?
  • Can unsupervised clusters of linguistic features distinguish humen- and LLM-generated texts?
  • Are there differences between instruction-tuned and non-instruction-tuned LLM in linguistic features?

Results

Sub-Research Question 1: To what extent and through which specific linguistic features can we distinguish between human-written and LLM-generated text? (Anwei Yan)

Group A: Tense and Aspect Markers

We first examines tense and aspect markers because they capture writing style through representation of time and action. These variables help us understand whether human and LLM-generated texts differ in narrative or descriptive style.

I will use ggcorrplot (pair plot) and heatmap to see the correlation between my variables, and use PCA and logistic regression to see the difference between llm and human.

Table 1 shows that the mean values of tense and aspect features are very similar between human and LLM-generated text. Past tense and present tense usage differ only slightly across the two groups, suggesting minimal separation based on average values alone. Perfect aspect is slightly higher in human text, but the difference is small in magnitude. Overall, this table indicates that mean comparisons alone provide limited evidence for distinguishing between human and LLM text. This motivates the need for more detailed distributional and model-based analysis.

The boxplots (Figure 1) reveal that while the median and other central distribution of tense and aspect features are similar across Human and LLM text, LLM-generated text tends to exhibit greater variability and more extreme values. The distributions overlap heavily, indicating that these features alone are not strong separators. However, the wider spread for LLM suggests less consistent usage patterns compared to human writing. This implies that differences may lie more in variability than in central tendency.

The correlation plot (Figure 2) shows a moderate negative relationship between past tense and present tense, suggesting that texts tend to emphasize one temporal perspective over the other. Perfect aspect is only weakly correlated with both, meaning that it captures a distinct dimension of language use. The relatively low correlations overall suggest that these features provide independent pieces of information.

The regression curves in Figure 3 indicate that tense and aspect features have relatively weak predictive power for distinguishing LLM from human text. Past tense and present tense show slight negative slopes, suggesting that higher values are weakly associated with human writing. In contrast, perfect aspect shows a strong negative slope, meaning that higher usage substantially decreases the probability of LLM classification. Despite this, predicted probabilities remain mostly above 0.5, indicating that these features alone are not sufficient for clear classification. Overall, tense and aspect features provide limited but still some signals that cannot be ignored.

Group B: Pronoun

Figure 4 shows that pronoun features have strong and highly differentiated effects on classification compared to Group A. First-person, third-person, “it,” and indefinite pronouns increase the probability of LLM classification, suggesting LLMs rely more on generalized and descriptive references. In contrast, demonstratives and the pro-verb “do” sharply decrease the probability, indicating these features are strongly associated with human writing. Second-person pronouns show a mild negative trend but remain less decisive. Overall, this graph demonstrates that pronoun usage is more informative for distinguishing human and LLM-generated text, and that effects are highly dependent on feature.

Group C: Subordination features

This graph (Figure 5) shows the subordination features with the largest differences in average usage between LLM and human text. Most features have positive values, indicating that LLM-generated text tends to use more complex constructions, such as present participles, infinitives, and that subjects, compared to human writing. In contrast, Because has a negative difference, meaning it is used more frequently in human text, which may reflect more direct, causal, and conversational expression. Overall, the graph suggests that LLMs have more structural complex and descriptive language, while humans use more straightforward and context-driven constructions.

The coefficient plot in Figure 6 shows that several subordination features have strong positive effects on the probability of a text being classified as LLM-generated, such as present participles and that subject, suggesting that increased use of these features is associated with LLM writing. In comparison, features such as WH object constructions, pied-piping, and Though have negative coefficients, suggesting they are more characteristic of human text. We can have a general takeaway that the model highlights that each of LLMs and human generated texts tend to favor certain types of linguistic feature in terms of subordination features, but it needs further research on these features to reach a more specific conclusion.

Conclusion

While linguistic features can be used to distinguish between human and LLM-generated text, this distinction is not uniform across all features. Instead, specific linguistic constructions such as pronoun usage and subordination structures are very useful in classification. LLM-generated text tends to favor structurally complex and generalized language, while human written text is more context-based and reference-grounded. These results suggest that stylistic differences between human and AI writing are not only detectable, but are deeply embedded in the grammatical choices rather than broad linguistic categories.

Sub-Research Question 2: Can unsupervised clusters of linguistic features distinguish humen- and LLM-generated texts? (Ting Chen)

We wanted to learn about not only whether texts from humans and LLM sources are different, but also between different LLM models. In order to make use of all 66 linguistic features, we applied Principal Component Analysis (PCA) to all the features. PCA is sensitive to number of samples in each category and we observe there are more LLM-generated samples compared to human-generated ones. Therefore we perform downsample so that each source has the same number of entries.

As shown in Figure Figure 7 there exists no strong principal component, with the most major component only accounted for \(15.4\) of the variation. This indicates that linguistic variation is distributed across many dimensions rather than concentrated in a single dominant pattern. Consequently, no strong low-dimensional structure clearly separates human and LLM texts.

Figure 8 suggests that there is no strong natural separation between human and LLM-generated texts in the reduced feature space, even though the ANOVA tests show that different sources differ in all principle components. Points from different sources overlap substantially across the first several principal components, indicating that the major dimensions of linguistic variation are shared across groups rather than source-specific. The spread of points also suggests that human texts are somewhat more compact and consistent, while some LLM sources, particularly Llama models, display greater variability. Overall, combined linguistic features alone do not produce clear unsupervised clusters by authorship source.

We also wanted to better understand whether individual texts group together by source when comparing overall linguistic similarity. To do this, we plotted sampled observations using hierarchical clustering with a dendrogram based on Euclidean distance in the standardized Biber feature space. To easily visualize the dendrogram, we randomly picked 10 samples from each source.

Figure 9 suggests that texts do not cluster into large branches defined by a single source. Instead, human and LLM texts are intermixed across many clusters, with only a few small local same-source groupings. This indicates that while some texts from the same source may share stylistic similarities, overall linguistic similarity is not dominated by whether a text was written by a human or a particular language model.

Conclusion

Together, these results suggest that unsupervised methods alone provide limited separation between human and LLM-generated writing. Even though after PCA, the metrics show texts from different sources are significantly different, they inherit similar writing style in general, with different degree of consistency. This means biber linguistic features are better designed for manual (supervised) classification and interpretation through the meaning of each feature, instead if general unsupervised classification

Sub-Research Question 3: Are there differences between instruction-tuned and non-instruction-tuned LLM in linguistic features? (Kevin Bao)

We wanted to examine if instruction-tuned and non-instruction-tuned LLMs write differently in terms of linguistic features. Instruction tuning is designed to make models follow human instruction more closely, so it is possible that this process also will change how language is used within the AI-generated text. First, in order to study this, we will be focusing firstly on “tense”, which is the most direct way of grammar used to investigate whether there is a different between instruction tuned AI generated text and non-instruction tuned AI generated text. In order to achieve this, we will create a boxplot:

The graph (Figure 10) above compares the use frequency of different tense-related linguistic features, that is, past tense, perfect and present, across instruction-tuned and non-instruction tuned LLMs, or specifically, Meta-Llama. The reason that I did not include GPT within this is because both versions of GPT are instruction-tuned LLMs, so they can not be directly compared with each other. In the graph, when comparing instruction tuned and non-instruction tuned versions, there are some noticeable differences. For the past tense part,we can see that the two non-instructed tuned graph has a higher median while having more outliers comparing to the instructed tuned graph, indicating that instructed-tuned graph tend to use past tense less. In addition, the range of non-instructed graph is a bit higher. For the perfect aspect, instructed tuned LLM have a slightly higher median, a slightly higher range, but less outlier. For the present tense part, the median and range difference become less significance even though that non-instructed LLM tend to have a slightly higher median and range comparing to the instructed LLMS.This suggest that instruction tuning does not dramatically change how tense is used in generated text, despite the small differences. The patterns of tense usage appear to be relatively stable across different versions of the models. Therefore, we can conclude that the tense alone may not be a strong feature for clearly distinguishing between instruction-tuned AI and non instruction-tuned AI. However, because of the results that the boxplot has shown is not that easy to notice, especially for “perfect tense”, we decided to do a t-test to see whats really going on:

After performing a t-test upon the means usage of tense features between instructed and non-instructed, the results shows that the differ in use of these three tense are statistically significant, with a P value of \(1.23\times 10^{-136}\). Specifically, we can that the non-instruction models tend to use more past tense and present tense while the instructed models use slightly more perfect aspect tense.However, the overall distribution, especially what was observed in the boxplot still appear quite similar, AI having a wider use of present and past tense while having a much less frequent use of perfect aspect tense.

After looking over the basic tenses, we will need to further investigates this question, we now examine whether instruction-tuned and non-instruction-tuned LLms differs in using pronouns. This pattern suggest that instruction tuned model may adopt a slightly more controlled and neutral lingusitic style, reducing the use of most type of pronouns. Now, we will take a look at the linguistic modal type of these LLMS.Within this, we have three linguistic modal types, which is necessity, which means that the LLM will speak in a certain tone, using words like “must”, possibility, which means that the LLM speak in a less certain voice, and predictive, which means that the LLM will tend to use words such as “Will”. We will use a heatmap to answer this question and to show the differences.

Conclusion

In conclusion, this part examines whether there are differences between instruction-tuned and non instruction tuned LLMs in terms of lingustic features. We have analyze tense, pronoun and linguistic feature modal type and we found out that although that there are differences, we can see that from the graphs, instructed tuned graphs have slighter higher use of perfect aspect while non-instruction-tuned models tend to use more past tense and present tense. In addition to this, as also shown in the third graph, non-instructed AIs tend to have a higher “necessity” modal usage while instructed have a higher “Possibility” modal usage. The second graph, has also shown different in language usage. These results suggest that instructions tuning may influence how models express tone, certainty in language and linguistic features, indicating that a instructed-tuned model tend to adopt to a more cautious and flexible style,its grammar usage is also considered more controlled. On the contrary, a non-instructed tuned model is much more straight forward and certain in its language. However, this does not mean that one is better than the other, to really examine this, more data and variables will be needed.

Future Work

While this project provides useful insights into how linguistic features related to different text sources, model types and other linguistic features, there are still several important questions that remain unanswered and could be furtherly explored in the future. First, although that our analysis shows that some linguistic features are different between instruction-tuned and non-instruction-tuned models, these different can not be considered a big difference except for the “Model Type” difference. This result is also consistent with the PCA graph, where no clear separations from different sources were shown because of the large overlapping of variables and points. Second our analysis mainly focuses on individual groups or types of linguistic features.Biber linguistic features provide a comprehensive overview of the text, but information is also lost in the numerical measures. In order to study LLM and LLM generated text better, it is helpful to focus on other meta variables as well. For examples, variables such as the genre and human prompt writer may largely influence how text is generated. Or in more detail, we should look at the original generated texts and extract other features like keywords, cooccurences words, etc. By a combination of some new variables and the lingusitic variables that we already have, there is a greater possibility that we will have a better insight into LLM generated texts.
