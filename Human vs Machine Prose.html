01 — Summary

Do machines write differently?

As AI-generated content becomes increasingly prevalent, understanding how machine-generated language differs from human writing matters for detection, evaluation, and broader NLP applications. This project asks whether linguistic features can distinguish human-written text from text generated by large language models — and whether that difference is uniform or feature-specific.

Using the Human–AI Parallel English Corpus (HAP‑E), we analyze 66 quantitative linguistic features spanning tense, pronouns, syntax, and discourse. Exploratory analysis, logistic regression, and supervised modeling show that linguistic features can meaningfully predict a text's source — in particular, features tied to pronoun usage, tense, sentence structure, and subordination were the most informative signals. Broadly, LLM-generated text leans on more generalized and structurally complex language, while human writing is more context-dependent and referentially grounded — though these differences are highly feature-specific rather than categorical.

Unsupervised analysis told a different story. PCA and hierarchical clustering revealed no strong natural separation between the two sources: observations substantially overlapped in reduced feature space, meaning the selected features are far better suited to supervised classification than to unsupervised discovery. We also found measurable differences between instruction-tuned and non-instruction-tuned LLMs, suggesting training objective itself leaves a linguistic signature.

Overall, linguistic features offer an interpretable but limited lens: authorship leaves a real signal in the grammar, but it's a signal built from many small, feature-specific effects rather than one dominant pattern.

02 — Data

The HAP‑E corpus

We use the Human–AI Parallel English Corpus (HAP‑E), built on the Biber (1988) feature set, available from the CMU S&DS Data Repository. The corpus is built from 12,000 original texts collected from a variety of real-world sources. For each, two ~500-word chunks were extracted: the first became a prompt asking an LLM to continue in the same style; the second — the original human continuation — anchors a direct, parallel comparison. Each row is one 500-word chunk.

  • Human The original chunk, written by the source's human author.
  • LLM The generated continuation, produced by several models including GPT‑4o and Llama, both pretrained and instruction-tuned.

The response variables are 66 linguistic features from multidimensional register analysis (Biber, 1988) — rates per 1,000 words across tense & aspect, pronouns & reference, syntactic structure, lexical complexity, and discourse markers.

03 — Research Questions

Three angles on one question

  • Can linguistic features distinguish between human- and LLM-generated texts?
  • Can unsupervised clusters of linguistic features distinguish human- and LLM-generated texts?
  • Are there differences between instruction-tuned and non-instruction-tuned LLMs in linguistic features?

Takeaway: linguistic features do distinguish sources, but unevenly — pronoun usage and subordination structure carry real signal; tense and aspect barely do. LLM text trends structurally complex and generalized; human text trends context-grounded and referentially direct.

05 — Results, RQ2

✎ Ting Chen

Do sources form natural clusters?

To use all 66 features at once, and to look beyond human-vs-LLM at differences between model families, we ran Principal Component Analysis on the full feature set. PCA is sensitive to class size and LLM samples outnumber human ones, so we downsampled every source to the smallest group's count first.

We also built a dendrogram from a 10-per-source sample, using Euclidean distance in standardized feature space.

Takeaway: sources are statistically distinguishable on every PCA axis, yet share enough overall stylistic structure that unsupervised methods can't cleanly separate them. These 66 features are built for supervised classification and interpretation — not for unsupervised discovery.

06 — Results, RQ3

✎ Kevin Bao

Does instruction-tuning change how a model writes?

Instruction tuning is meant to make a model follow human intent more closely — does that process also leave a mark on its grammar? We compare four Llama‑3 checkpoints (8B/70B, base vs. Instruct); GPT‑4o variants are excluded here since both are instruction-tuned and can't provide a within-family contrast.

Takeaway: instruction tuning doesn't overhaul a model's grammar, but it does nudge it — toward hedged, flexible, lower-certainty phrasing, and modestly reduced pronoun use. Neither style reads as objectively "better," just differently calibrated.

07 — Future Work

Open threads

Instruction-tuning differences, while real, are modest next to the base human/LLM gap — consistent with the PCA finding that no single axis cleanly separates any of these groups. And because Biber features summarize text numerically, some information is necessarily lost: metadata like genre or the human prompt-writer, and finer-grained signals like specific keyword or co-occurrence patterns, could sharpen the picture if layered on top of the linguistic feature set used here.
